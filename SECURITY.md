# Security Policy

## Supported Versions

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |

## Reporting a Vulnerability

If you discover a security vulnerability in **Lithotheque Server** (`lithotheque-server`), please report it privately using GitHub's **[Private Vulnerability Reporting](../../security/advisories/new)** form.

**Do not report security vulnerabilities through public GitHub issues, discussions, or pull requests.**

Please include:
- A description of the vulnerability and its potential impact.
- Steps to reproduce the issue.
- Any relevant logs or configuration details.
